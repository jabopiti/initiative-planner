# Demo export

`demo.json` is a fictional dataset for exercising the tool without typing one
in. Import it through **Settings → Data → Import**, choosing **Replace all**.

Everything in it is invented. The people, teams, countries and day rates are
placeholders, as they are everywhere else in this repository.

## What it contains

One initiative resting in each phase of the placeholder process, so every
state the UI can show is represented:

| Initiative | Where it is | Why it's here |
|---|---|---|
| Customer portal refresh | Discovery | Estimated but not yet gated |
| Payments migration | Validation | One gate passed |
| Warehouse automation | Development | **Skipped** its first gate, and has recorded actuals — so it reads as a forecast, not an estimate |
| Supplier portal | Rollout | Past both costed gates, phases frozen |
| Fraud scoring v2 | Closed | Finished by passing the final gate, and frozen |
| Loyalty scheme | Discovery, **On hold** | Excluded from capacity, still costed |

It also carries the two people-model cases worth seeing:

- **Ada Vance** is split across both teams, so each team's capacity grid and
  run-rate chart draw on its own share of her — and her non-initiative work
  divides between them rather than counting twice.
- **Di Marchetti** is on a custom rate: an individually negotiated day rate
  per year, with no role factor applied, but still observing their country's
  working days.

## Regenerating

```bash
npm run demo
```

The file is **generated by driving the real engine and lifecycle functions**,
never written by hand. A hand-built fixture can express states the code can
never produce, and then rots silently when the rules change. If this script
cannot build something, the app cannot reach it either.

The generator freezes the clock while it runs, so ids stay stable and
regenerating produces a readable diff rather than a wall of churn.

## If the import is refused

An export records the **schema version** and the **process** it was written
against, and an import disagreeing with the running build is refused outright
(SPEC §8). If this file is rejected, it was generated against an older build:
regenerate it with the command above.
